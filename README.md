# The Most Complicated Lock Pattern Game

A standalone browser puzzle about drawing lock patterns that use every possible slope in a square grid. The project runs entirely in the frontend: all move validation, slope calculation, color assignment, and win checking are implemented in TypeScript under `src/lib/lockRules.ts`.

Concept link: https://www.youtube.com/watch?v=PKjbBQ0PBCQ

This website was generated by codex + gpt-5.5.

## Rules

1. Choose a 3x3, 5x5, or 7x7 grid.
2. Draw one continuous lock pattern by swiping across points or by switching to click mode.
3. Each point can be used only once.
4. A long straight jump is legal only if every intermediate point on that exact line has already been selected.
5. Every segment contributes one slope. Horizontal lines count as slope `0`; vertical lines count as slope `infinity`; all other slopes are reduced fractions.
6. To solve a grid, the pattern must use every unique slope available in that grid at least once.
7. The slope panel shows used and missing slopes. Selecting a slope highlights matching segments in the current pattern.

## Available Grids

| Grid | Points | Unique slopes | Difficulty |
| --- | ---: | ---: | --- |
| 3x3 | 9 | 8 | Starter |
| 5x5 | 25 | 24 | Strategic |
| 7x7 | 49 | 48 | Extreme |

## Local Development

Requirements:

- Node.js 22 or newer
- npm

Install dependencies:

```bash
npm ci
```

Run the local dev server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

Run checks:

```bash
npm run check
```

Build the static site:

```bash
npm run build
```

The static output is written to `out/`.

## GitHub Pages Deployment

This repository includes `.github/workflows/deploy.yml`. On every push to `main`, GitHub Actions installs dependencies, runs `npm run build`, uploads the `out/` folder, and deploys it to GitHub Pages.

To publish on GitHub:

1. Create an empty GitHub repository.
2. Add the remote:

```bash
git remote add origin git@github.com:<your-user>/<your-repo>.git
```

3. Push the local repository:

```bash
git push -u origin main
```

4. In GitHub, open the repository settings.
5. Go to `Pages`.
6. Set the source to `GitHub Actions`.
7. Wait for the `Deploy static site to GitHub Pages` workflow to finish.

## Custom Domain

For a custom domain:

1. Add your domain in GitHub repository settings under `Pages` -> `Custom domain`.
2. Create `public/CNAME` with exactly your domain name, for example:

```text
locks.example.com
```

3. Commit and push `public/CNAME`.
4. Configure DNS with your domain provider:
   - For a subdomain, add a `CNAME` record pointing to `<your-user>.github.io`.
   - For an apex domain, add GitHub Pages `A` and `AAAA` records from GitHub's current Pages documentation.
5. Enable `Enforce HTTPS` after DNS validation succeeds.

If you deploy without a custom domain to a project URL like `https://<your-user>.github.io/<your-repo>/`, add a `basePath` and `assetPrefix` in `next.config.ts` before building.
